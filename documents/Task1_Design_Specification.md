## 1. 題目定義 (Problem Definition)

本系統旨在模擬香港中學學位分配辦法（SSPA）中的「統一派位」機制。系統需處理大量學生與學校數據，根據學生的校內成績（呈分試）計算派位組別（Banding），並結合隨機編號與志願順序進行公平分配。

### 目標 (Objectives)
1.  **數據導入**：能夠讀取學校 (`school.csv`) 和學生 (`students.csv`) 的原始數據。
2.  **成績運算**：根據教育局建議的比重（中英數 x9，常識 x6 等）計算學生總分。
3.  **組別劃分**：將學生按總分排序，平均分為 Band 1, Band 2, Band 3 三個組別。
4.  **隨機分配**：在同一組別內，利用隨機編號解決同分或學額競爭問題。
5.  **結果輸出**：生成分配結果文件 (`assign.csv`) 並提供查詢介面。

## 2. 系統流程設計 (Algorithm Design)

系統的核心分配邏輯如下：

1.  **驗證階段**：
    *   檢查 CSV 檔案是否存在。
    *   驗證學生分數是否在 0-100 合法範圍。
    *   驗證學生選填的學校 ID 是否存在於學校名單中。
    
2.  **預處理階段**：
    *   計算每位學生的加權總分。
    *   全體學生按總分降序排列 (Sorting)。
    *   前 1/3 學生歸入 `Band 1`，中間 1/3 歸入 `Band 2`，後 1/3 歸入 `Band 3`。

3.  **分配階段 (核心算法)**：
    *   **隨機化**：對每個 Band 內的學生列表進行 `Random Shuffle` (打亂)，模擬隨機編號。
    *   **循環處理**：依次處理 Band 1 -> Band 2 -> Band 3。
    *   **志願匹配**：
        *   讀取學生當前志願（第1志願開始）。
        *   檢查該學校是否有剩餘學額 (`quota > 0`)。
        *   **若有學額**：分配成功，學校學額 -1，學生移出待分配隊列。
        *   **若無學額**：學生志願序號 +1，將學生移至隊列尾部等待下一輪嘗試。
        *   若所有志願均落空，標記為「無法分配」。

## 3. 數據結構 (Data Structures)

本系統使用 Python 的內建數據結構來優化存取效率：

### 3.1 學生資料庫 (`students_data`)
使用 **字典 (Dictionary)** 存儲，鍵 (Key) 為學生 ID，實現 O(1) 快速查詢。

| 鍵 (Key) | 值類型 (Value Type) | 描述 |
| :--- | :--- | :--- |
| `student_id` | String | 唯一識別碼 (例如: KT2025001) |
| (Value) | Dictionary | 包含 `name`, `scores`, `ss_choices`, `total_score`, `banding` 等詳細資料 |

### 3.2 學校名額表 (`school_quota`)
使用 **二維列表 (2D List)** 存儲學校 ID 與剩餘名額，便於遍歷與更新。

```python
[
    ['KTSS001', 120],  # [學校ID, 剩餘名額]
    ['KTSS002', 85],
    ...
]
```

### 3.3 分配隊列 (band1, band2, band3)
使用 列表 (List) 作為隊列 (Queue)，配合 pop(0) 和 append() 操作來實現學生的循環分配。

## 4. 使用者介面設計 (UI Design)

系統採用 Tkinter 構建圖形介面 (GUI)，包含以下模組：

- 檔案匯入區：顯示目前選擇的 CSV 路徑。
- 操作控制區：包含「開始分配」、「數據驗證」等功能按鈕。
- 狀態顯示區：即時顯示程式運行狀態（如：正在處理 Band 1...）。
- 查詢系統：允許用戶輸入學生 ID，顯示其分配結果及詳細資料。
