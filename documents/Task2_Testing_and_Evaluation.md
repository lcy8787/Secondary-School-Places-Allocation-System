## 2. 成果總結與技術限制評估

### 設計的優點

#### 1. 高度模擬現實的排位算法
系統模擬了香港小學升中學的派位系統，程式的結果貼近真實的排位。當中考慮到學生的自願選擇、學校的擁有的學額、以及隨機變量，還原實際的操作流程。

#### 2. 嚴謹的學額分配機制
系統按照學校學額進行分配，在分配過程之中，持續檢查學校是否達致其分配額限額，確保所分配的學生不會被超額錄取。以 `school_quota` 二維陣列儲存每所學校還擁有的學額，當學生獲分配到學校後，其值減 1。

#### 3. 直觀友好的圖形使用者介面 (GUI)
有別於使用終端機來顯示數據，本系統利用 Python Tkinter 創立了圖形使用介面，減少了用戶的使用門檻，令不熟悉編程的人也能透過點擊按鈕運行程式，提升用戶體驗及易用性。

#### 4. 全面的數據完整性檢測
系統擁有多層的數據驗證，包括：檔案是否缺失、數據是否符合格式、數據是否正確（如分數範圍）。當發生錯誤時，程式會即時中斷並彈出 `messagebox` 提示，並在終端機列出詳細錯誤原因，防止程式崩潰。

### 技術限制與缺點

1.  **缺乏數據統計與分析功能**: 程式的核心功能僅限於進行升中排位，無法統計其分配結果（例如：首志願獲派百分比），用戶需使用其他工具分析。
2.  **缺乏標準化日誌記錄功能**: 系統錯誤訊息僅輸出在終端機，缺乏標準化的 Log 檔案，令開發者難以追蹤程式在後台的長期運行情況。

### 改善方法及展望

1.  **整合數據統計庫**: 引入 `pandas` 或 `matplotlib` 生成統計圖表，自動生成學生派位滿意度等統計資料。
2.  **實施標準化日誌**: 利用 Python `logging` 模組建立日誌記錄，將程序事件寫入日誌文件，方便追蹤運行軌跡及除錯。
